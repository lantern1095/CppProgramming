## 일반생성자와 복사생성자의 차이는?
- 일반생성자 : 객체를 처음 생성할때 호출된다. 사용자가 지정한 값으로 초기화한다.
- 복사생성자 : 객체를 처음 생성함과 동시에 원본 객체를 이용하며 생성할 때 호출, 원본 객체의 값으로 초기화

## 대입연산과 얕은 복사생성자의 차이는 무엇인가?
- 대입연산 : 이미 만들어진 객체에 값을 넣는 것, 객체 생성 이후에 값을 대입할 떄 대입연산이 이루어진다. 
- 얕은 복사생성자 : 객체를 생성함과 동시에 값을 복사한다. 맴버 변수의 값을 그대로 복사하는 것에 지나지 않아 동적 할당을 사용하였다면, 같은 메모리 고간을 사용하게 되는 문제가 있다.
