## 참조에 의한 호출과 주소에 의한 호출의 차이점을 설명하라.
- 함수의 매개 변수를 참조로 선언하면, 함수 호출시 참조 매개 변수의 이름만 생기고 메모리 공간은 할당되지 않는다. -> 인자로 참조 매개변수를 초기화하게 되며, 인자가 원본이 되고 참조 매개변수가 인자의 별명이 된다.
- 주소에 의한 호출은 포인터 변수를 매개 변수로 하며, 함수 호출시 인자의 메모리 주소로 초기화한다.

## 참조에 의한 호출의 장점은 무엇인가?
- 매개변수 할당과 인자값을 매개변수에 복사하는 과정이 필요 없기에, 그만큼 실행 시간이 빨라지게 된다. 또한 값에 의한 호출처럼 사용이 간편하면서도, 주소에 의한 호출과 같은 효과를 가지기에 사용하기에 편리하다.
