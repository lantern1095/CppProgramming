## 인자와 매개변수를 구분하여 설명하시오.
- 인자는 함수를 호출할 때 함수로 전달하는 값이다.
- 매개변수는 함수의 지역 변수로서, 함수 호출 시 매개변수 객체가 메모리에 생성되고 인자의 값이 매개변수에 복사된다.
## 함수 호출시 자동으로 처리되는 2가지는 무엇인가?
- 매개변수 객체가 메모리에 생성되고, 호출하는 쪽의 인자의 값이 매개변수에 복사된다. (인자로 초기화됨)

## 값에 의한 호출로 다른 함수에서 선언된 변수의 값을 변경할 수 없다. 이유를 설명하라.
- 함수를 호출할 때 넘기는 인자 값과 함수의 매개 변수는 값이 같아 자칫 동일하다고 착각하기 쉽지만, 서로 다른 함수에 선언된 지역 변수이며 기본적으로 동일하지 않다. 또한 매개변수 객체는 함수 종료시 같이 소멸되기 때문에 값에 의한 호출로 변수의 값을 직접 바꿀 수는 없다.

## 주소에 의한 호출을 사용해야하는 경우를 2가지 이상 설명하라.
- 다른 함수의 값을 직접 바꾸기 위해서는 값이 아니라 해당 변수의 주소로 직접 접근하여 변경 해주어야 한다.
- 주소만 복사하면 되므로 객체를 복사하는데 걸리는 시간을 절약할 수 있다.

## 인자가 객체인 경우는 어떤 호출방식이 좋은가? 이유도 설명하라
- 객체의 주소만 복사하면 되어 시간 절약에 용이한 주소에 의한 호출 방식이 유리하다.

## 함수 반환과정에서 자동으로 처리되는 2가지는 무엇인가?
- 임시변수가 할당되고 반환값으로 초기화된다, 또한 함수 호출문이 임시 변수로 대체되고 대입연산을 거친 후 임시변수는 소멸된다.

## 함수 반환과정에서 임시변수가 필요한 이유를 설명하라
- 반환값은 함수 내부에서 선언된 지역 변수이므로 함수 반환 후 메모리에서 소멸된다. 따라서 소멸하기 전에 임시 변수로 백업하는 것이다.
