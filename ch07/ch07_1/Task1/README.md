## 프렌드 함수가 왜 필요한가?
- 클래스의 private으로 지정된 멤버는 외부 함수에서 직접 접근하는 것이 불가능 하기에, 연산자 함수 등을 이유로 접근을 해야하는 특별한 상황에서는 프렌드 함수를 사용하여 클래스의 모든 멤버를 접근할 수 있는 권한을 부여한다.

## 객체 지향형 언어의 특징 중의 하나인 다형성의 의미와 종류를 조사하시오
- 하나의 이름이나 인터페이스가 여러 가지의 형태로 동작하는 성질이다.
- 다형성의 종류로는 함수 오버로딩(동일 함수명 사용, 매개변수로 구분) / 연산자 오버로딩(기존 연산자를 재정의) / 함수 오버라이딩(상속 관계에서 부모 클래스의 함수를 자식 클래스에서 재정의) 등이 있다.
